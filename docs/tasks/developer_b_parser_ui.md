# 开发者 B 任务：文件解析、AI 辅助与页面

## 主责范围

```text

-> export
```

## 任务 B1：文件上传与绑定

目标：用户可为报价任务上传 PDF、STEP 和附件。

必须实现：

| 能力 | 要求 |
|---|---|
| 上传 PDF | 校验扩展名、大小、文件记录。 |
| 上传 STEP | 支持 `.step`、`.stp`。 |
| 上传附件 | 可保存但不参与第一版自动核价。 |
| 文件版本 | 同一任务同类文件支持多版本。 |
| 文件绑定 | 文件必须绑定 `quote_task`。 |
| 缺文件提示 | 缺 PDF 或 STEP 时生成风险提示。 |

验收标准：

- 上传成功后生成 `part_file`。
- 失败时给出结构化错误。
- 页面显示文件类型、版本、状态。

## 任务 B2：PDF 图纸解析

输入：PDF 文件。

输出：`pdf_extract_result`

必须抽取：

| 字段 | 要求 |
|---|---|
| 图号 | 保存原文和置信度。 |
| 零件名称 | 保存原文和置信度。 |
| 版本 | 保存原文和置信度。 |
| 材料 | 保存原文和置信度。 |
| 重量 | 保存原文、数值、单位、置信度。 |
| 比例 | 保存原文和置信度。 |
| 热处理 | 保存原文和置信度。 |
| 表面处理 | 保存原文和置信度。 |
| 公差 | 保存原文和置信度。 |
| 粗糙度 | 保存原文和置信度。 |
| 技术要求 | 保存原文和置信度。 |

验收标准：

- PDF 关键字段抽取准确率 >= 90%。
- 每个字段必须有来源证据。
- 低置信度字段必须标记风险。

## 任务 B3：STEP 解析适配

输入：STEP 文件。

输出：`step_feature_result`

必须输出：

| 字段 | 要求 |
|---|---|
| 包络尺寸 | 长、宽、高、单位。 |
| 体积 | 数值、单位。 |
| 表面积 | 数值、单位。 |
| 理论净重 | 基于材料密度计算时必须说明密度来源。 |
| 零件类型候选 | 薄片件、板件、块件、轴类件、复杂件。 |
| 孔特征 | 普通孔、盲孔、沉孔、沉头孔、螺纹孔、精孔候选。 |
| 复杂度特征 | 面数、边数、窄槽、小 R、薄壁等。 |

验收标准：

- STEP 基础几何解析成功率 >= 95%。
- 解析失败必须可展示原因。
- 不支持的复杂件必须标记转人工。

## 任务 B4：AI 文本归一与解释

允许 AI 做：

| 能力 | 输出 |
|---|---|
| 材料归一 | 标准材料编码、原文、置信度。 |
| 表面处理归一 | 标准表面处理编码、原文、置信度。 |
| 热处理识别 | 热处理要求、原文、置信度。 |
| 工序解释 | 基于 A 输出的规则命中原因生成说明。 |
| 风险提示说明 | 将结构化风险转换为用户可读提示。 |

禁止 AI 做：

- 直接决定最终报价。
- 直接覆盖价格规则。
- 在无证据时生成关键字段。
- 改写 A 输出的工序规则结果。

验收标准：

- AI 输出必须保留原文证据或输入依据。
- AI 输出必须可降级，失败时不阻塞规则计算。

## 任务 B5：核对页面

页面必须展示：

| 区域 | 内容 |
|---|---|
| 文件区 | PDF、STEP、附件、版本、解析状态。 |
| 零件特征区 | 材料、尺寸、重量、孔、精度、表面处理、热处理。 |
| 工序区 | 工序顺序、触发原因、置信度、待确认标记。 |
| 工程量区 | 工程量、单位、公式、依据。 |
| 报价明细区 | 单价、数量、金额、价格来源、公式。 |
| 风险区 | 风险等级、说明、是否必确认。 |
| 人工修改区 | 修改工序、价格、金额、原因。 |
| 汇总区 | 初始报价、调整后报价、最终确认价。 |

页面状态必须覆盖：

| 状态 | 要求 |
|---|---|
| loading | 正在解析或核价。 |
| success | 已生成结果。 |
| warning | 存在待确认风险。 |
| error | 解析或核价失败。 |
| readonly | 已确认或已作废。 |

验收标准：

- 修改原因必填。
- 有 blocking 风险时不得确认。
- 初始报价和最终确认价可对比。

## 任务 B6：报价导出

必须导出：

| 内容 | 要求 |
|---|---|
| 任务信息 | 客户、零件、图号、数量。 |
| 文件信息 | 文件名、版本。 |
| 工艺路线 | 工序、原因、置信度。 |
| 工程量 | 数量、单位、公式。 |
| 报价明细 | 单价、金额、价格来源。 |
| 风险提示 | 风险编码、说明、确认状态。 |
| 修改记录 | 修改字段、旧值、新值、原因。 |
| 汇总 | 初始报价、最终确认价。 |

验收标准：

- 导出结果与页面显示一致。
- 导出包含修改记录。
- 导出操作记录日志。

## B 与 A 的联调点

| 联调点 | B 需要提供 | A 需要提供 |
|---|---|---|
| 文件记录 | `part_file` | 任务状态接口 |
| `part_feature` | 解析和融合结果 | 消费和校验 |
| 核价结果 | 页面展示 | `quote_result` |
| 人工修改 | 表单输入 | 保存接口 |
| 导出 | 模板和下载 | 结构化报价数据 |

## B 的 PR 检查清单

提交前确认：

- 是否只改当前 Issue。
- 页面是否覆盖 loading、success、warning、error。
- 是否没有依赖未文档化字段。
- 是否保留 AI 输出证据和置信度。
- 是否未让 AI 决定最终报价。
- 是否处理文件缺失和解析失败。
- 是否说明对 A 的接口影响。
