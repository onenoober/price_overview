## 任务 A1：数据库与核心模型

目标：建立报价核心数据结构。

必须覆盖数据对象：

| 对象 | 说明 |
|---|---|
| `quote_task` | 报价任务主表。 |
| `part_feature` | 融合后零件特征快照。 |
| `process_route` | 工序路线和候选结果。 |
| `engineering_quantity` | 工程量结果。 |
| `price_rule` | 价格规则。 |
| `price_source_record` | 价格来源。 |
| `quote_item` | 报价明细。 |
| `quote_summary` | 报价汇总。 |
| `human_override` | 人工修改记录。 |
| `quote_history_sample` | 历史样本。 |

验收标准：

- 数据迁移可重复执行。
- 所有金额字段精度可控。
- 所有核心表有创建时间、更新时间。
- 报价结果保存价格版本。
- 人工修改不覆盖系统初始值。

## 任务 A2：基础字典

目标：建立规则计算所需字典。

字典：

| 字典 | 必要字段 |
|---|---|
| 材料字典 | 材料编码、名称、别名、密度、类别、状态。 |
| 工序字典 | 工序编码、名称、类型、排序、是否自动报价。 |
| 表面处理字典 | 编码、名称、别名、默认计价单位。 |
| 风险标签字典 | 编码、等级、是否必确认、默认提示。 |
| 单位字典 | 单位编码、名称、类型、换算规则。 |

验收标准：

- 字典可查询。
- 字典编码稳定。
- 规则只能引用标准编码，不得引用展示名称。

## 任务 A3：工序识别

输入：`part_feature`

输出：`process_route`

必须实现：

| 能力 | 要求 |
|---|---|
| 触发规则 | 根据材料、几何、孔、精度、热处理、表面处理触发工序。 |
| 冲突消解 | 处理 CNC/线切割、钻孔/精孔、热前/热后加工等冲突。 |
| 工序排序 | 按标准工艺顺序输出。 |
| 触发原因 | 每个工序必须保存原因。 |
| 置信度 | 每个工序必须有 0-1 置信度。 |
| 待确认 | 低置信度、高风险、未知字段必须标记。 |

验收标准：

- 必选工序召回率 >= 90%。
- 工序误判率 <= 15%。
- 每个工序均有解释依据。

## 任务 A4：工程量计算

输入：`part_feature`、`process_route`

输出：`quantity_result`

必须实现：

| 工序 | 工程量口径 |
|---|---|
| 材料 | 毛坯长 × 毛坯宽 × 毛坯厚 × 密度。 |
| 线切割 | 切割长度 × 材料厚度。 |
| 钻孔 | 普通孔数量。 |
| 沉孔 | 沉孔数量。 |
| 攻牙 | 螺纹孔数量。 |
| 精孔 | 高精度孔数量。 |
| CNC | 粗加工体积、面数、复杂度或估算工时。 |
| 磨削 | 磨削面积、件数或估算工时。 |
| 热处理 | 成品重量、毛坯重量或炉次摊销。 |
| 表面处理 | 净重或表面积。 |
| 去毛刺 | 件数、边数、边长或复杂度。 |
| 检验包装 | 件数、关键尺寸数量、外观保护要求。 |

验收标准：

- 每项工程量有公式。
- 每项工程量有单位。
- 每项工程量有计算依据。
- 无法计算时生成风险，不填虚假值。

## 任务 A5：价格规则

目标：建立价格规则维护和匹配能力。

必须支持：

| 能力 | 要求 |
|---|---|
| 材料价格 | 按材料编码和生效版本匹配。 |
| 工序价格 | 按工序编码、单位、规则条件匹配。 |
| 表面处理价格 | 按表面处理编码匹配。 |
| 起步价 | 工序可配置起步价。 |
| 调机费 | 工序可配置调机费和摊销方式。 |
| 风险附加 | 按风险标签加价。 |
| 价格来源 | 保存档案导入、人工维护、供应商报价、历史参考。 |
| 版本管理 | 生效日期、失效日期、审核状态。 |

验收标准：

- 未审核价格不得参与正式计算。
- 价格缺失必须生成 `MISSING_PRICE`。
- 每个报价项能追溯价格来源。

## 任务 A6：报价计算

输入：`quantity_result`、`price_rule`、风险项。

输出：`quote_result`

必须实现公式：

```text
材料费 = 毛重 × 材料单价
加工费 = Σ max(工序工程量 × 工序单价, 工序起步价)
表面处理费 = Σ(表面处理工程量 × 表面处理单价)
管理费 = 材料费 × 5%（固定规则）
税金 = (加工费 + 表面处理费 + 管理费) × 税率
系统计算价 = 材料费 + 加工费 + 表面处理费 + 管理费 + 税金
系统初始报价 = 系统计算价按取整规则和报价规则生成
最终确认价 = 报价员确认或修改后的价格
```

第一版加工费使用 `docs/modules/quote_calculation.md` 中的 `华南工序计价标准表`。材料单价可使用实时市场搜索生成待复核价格；工序单价不依赖每次实时搜索。化学镍进入表面处理费，不进入加工费。

验收标准：

- 报价明细可解释率 100%。
- 初始报价保存后不可被人工修改覆盖。
- 有必确认风险时状态为 `pending_review`。

## 任务 A7：人工修改与历史样本

必须实现：

| 能力 | 要求 |
|---|---|
| 修改记录 | 保存目标对象、字段、旧值、新值、原因、操作人、时间。 |
| 修改原因 | 必填。 |
| 初始值保留 | 系统初始报价和原始明细必须保留。 |
| 最终确认 | 保存确认人、确认时间、确认总价。 |
| 历史样本 | 保存输入、初始报价、人工修改、最终结果。 |

验收标准：

- 人工修改记录完整率 100%。
- 历史样本可用于后续偏差分析。
