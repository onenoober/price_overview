# 工程量计算模块

## 模块目标

根据 `part_feature` 和 `process_route` 计算各工序工程量，输出 `quantity_result`。工程量必须有数值、单位、公式和依据。

## 主责

开发者 A 主责。

## 输入

| 输入 | 说明 |
|---|---|
| `part_feature` | 零件几何、材料、制造要求。 |
| `process_route` | 工序路线。 |
| 计算参数 | 毛坯余量、默认工时、阈值等。 |

## 输出

| 输出 | 说明 |
|---|---|
| `quantity_result` | 工程量结果。 |
| 计算风险 | 无法计算、缺字段、需人工确认。 |

## 工程量口径

| 工序 | 工程量类型 | 口径 | 单位 |
|---|---|---|---|
| 材料 | `gross_weight` | 毛坯长 × 毛坯宽 × 毛坯厚 × 密度 | kg |
| 线切割 | `cut_area` | 外轮廓长度 × 材料厚度 | mm2 |
| 钻孔 | `hole_count` | 普通孔数量 | pcs |
| 沉孔 | `counterbore_count` | 沉孔数量 | pcs |
| 攻牙 | `thread_count` | 螺纹孔数量 | pcs |
| 精孔 | `precision_hole_count` | 高精度孔数量 | pcs |
| CNC | `estimated_hours` | 装夹、上下表面、外轮廓、槽/小R和复杂度修正估算工时 | hour |
| 磨削 | `grinding_area` | 磨削面积或估算工时 | mm2/hour |
| 热处理 | `heat_weight` | 成品重量、毛坯重量或炉次摊销 | kg |
| 表面处理 | `surface_area` | 化学镍、阳极氧化、镀硬铬、喷塑、喷砂等优先使用 STEP 表面积并换算为 m² | m2 |
| 去毛刺 | `deburr_complexity` | 件数、边数、边长或复杂度 | score |
| 检验包装 | `inspection_count` | 件数、关键尺寸数量、保护要求 | pcs |

## CNC 估算工时口径

CNC 工程量输出 `estimated_hours`，只表示可解释的估算机时，不直接输出金额。金额由报价模块按小时单价、最低消费、编程费、管理费等价格规则计算。

当前 CNC 工时不包含钻孔、沉孔、攻牙、精孔、去毛刺、表面处理、检验和包装；这些已经由独立工序工程量计算，避免重复计价。

推荐第一版公式：

```text
CNC估算分钟 =
装夹分钟
+ 上下表面铣削分钟
+ 外轮廓铣削分钟
+ 槽特征分钟
+ 小R修正分钟
+ 复杂度修正分钟
+ 翻面找正分钟

CNC估算工时 = CNC估算分钟 / 60
```

默认参数：

| 参数 | 默认值 | 说明 |
|---|---:|---|
| 单次装夹 | 5 min | 初始装夹、找正、对刀。 |
| 翻面找正 | 0 min | 第一版不自动推断翻面；需要时人工复核或后续规则补充。 |
| 铣面效率 | 5500 mm2/min | 普通钢小件经验效率。 |
| 外轮廓进给 | 500 mm/min | 外轮廓铣削经验进给。 |
| 外轮廓走刀圈数 | 2 | 粗铣/精铣或分层加工的简化系数。 |
| 单槽修正 | 2 min | STEP 识别到槽候选时增加。 |
| 小R修正 | 0.5 min | STEP 识别到小R候选时增加。 |
| 复杂度基准 | 30 | `complexity_score` 高于该值后增加修正。 |
| 复杂度修正 | 0.05 min/score | `(complexity_score - 30) × 0.05`。 |

组件公式：

```text
上下表面面积 = 2 × 主加工面长 × 主加工面宽
上下表面铣削分钟 = 上下表面面积 / 铣面效率

外轮廓长度 = STEP outer_profile_length
若 STEP 未提供，则矩形板/块件按 2 × (主加工面长 + 主加工面宽) 兜底估算
外轮廓铣削分钟 = 外轮廓长度 × 走刀圈数 / 外轮廓进给

槽特征分钟 = slot_count × 单槽修正
小R修正分钟 = small_radius_count × 小R修正
复杂度修正分钟 = max(0, complexity_score - 30) × 复杂度修正
```

材料系数用于修正铣削分钟，不修正装夹分钟：

| 材料 | 系数 |
|---|---:|
| 铝 / AL6061 | 0.8 |
| 普通钢 / S45C | 1.0 |
| SUS304 / 不锈钢 | 1.3 |
| SKD11 / DC53 / Cr12MoV / 模具钢 | 1.4 |

CNC 工时采用默认节拍参数时，必须保留 `requires_review=true` 和结构化风险，提示复核装夹次数、是否翻面、实际机台节拍和材料加工系数。

## 计算项结构

每个工程量项必须包含：

| 字段 | 说明 |
|---|---|
| `operation_code` | 对应工序编码。 |
| `quantity_type` | 工程量类型。 |
| `value` | 数值。 |
| `unit` | 单位。 |
| `formula` | 公式。 |
| `basis` | 输入依据。 |
| `requires_review` | 是否待确认。 |

## 异常处理

| 情况 | 处理 |
|---|---|
| 缺尺寸 | 生成风险，不计算材料毛重。 |
| 缺密度 | 生成未知材料或密度缺失风险。 |
| 孔特征低置信度 | 工程量可输出但标记待确认。 |
| 复杂度无法估算 | 生成待确认风险。 |
| 单位不一致 | 先转换为标准单位，保存转换依据。 |

## 不做什么

- 不匹配价格。
- 不生成报价金额。
- 不重新解析 PDF 或 STEP。
- 不把无法计算的值填为 0。

## 验收标准

- 每项工程量有公式、单位和依据。
- 无法计算时有结构化风险。
- 工程量输出通过 Schema 校验。
- 工程量能被报价计算直接消费。

## AI Coding 注意事项

- 不要把计算依据写成普通备注后丢失结构。
- 不要在多个模块重复实现同一公式。
- 不要混用 mm、cm、m 而不显式换算。
- 不要让价格计算重新推导工程量。
