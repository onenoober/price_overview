# 价格规则模块

## 模块目标

维护和匹配材料、工序、表面处理、起步价、调机费、风险附加等价格规则。价格规则模块提供价格来源和版本，不直接处理页面人工修改。

## 主责

开发者 A 主责。

## 输入

| 输入 | 说明 |
|---|---|
| 材料字典 | 标准材料编码。 |
| 工序字典 | 标准工序编码。 |
| 表面处理字典 | 标准表面处理编码。 |
| 价格档案 | 导入或人工维护的价格。 |
| 审核状态 | 价格是否可生效。 |

## 输出

| 输出 | 说明 |
|---|---|
| `price_rule` | 可匹配价格规则。 |
| `price_source_record` | 价格来源记录。 |
| 价格缺失风险 | `MISSING_PRICE`。 |

## 价格规则字段

| 字段 | 说明 |
|---|---|
| `rule_id` | 规则 ID。 |
| `rule_code` | 稳定规则编码。 |
| `price_type` | `material`、`process`、`surface_treatment`、`risk_surcharge`。 |
| `target_code` | 材料、工序或表面处理编码。 |
| `unit` | 计价单位。 |
| `unit_price` | 单价。 |
| `min_amount` | 起步价。 |
| `setup_fee` | 调机费。 |
| `condition` | 适用条件。 |
| `source_type` | 档案导入、人工维护、供应商报价、历史参考。 |
| `source_id` | 来源 ID。 |
| `version` | 价格版本。 |
| `effective_from` | 生效日期。 |
| `effective_to` | 失效日期。 |
| `approval_status` | `draft`、`approved`、`disabled`。 |

## 匹配规则

| 场景 | 匹配要求 |
|---|---|
| 材料费 | 按材料编码、价格版本、日期匹配。 |
| 工序费 | 按工序编码、单位、条件匹配。 |
| 表面处理费 | 按表面处理编码匹配。 |
| 风险附加 | 按风险编码和适用工序匹配。 |
| 起步价 | 工序金额低于起步价时使用起步价。 |
| 调机费 | 按工序配置加到报价项或摊销。 |

## 审核规则

| 状态 | 是否可参与报价 |
|---|---|
| `draft` | 否 |
| `approved` | 是 |
| `disabled` | 否 |

## 异常处理

| 情况 | 处理 |
|---|---|
| 无材料价格 | 生成 `MISSING_PRICE`。 |
| 无工序价格 | 生成 `MISSING_PRICE`。 |
| 多条价格同时命中 | 按优先级选择，并记录匹配原因。 |
| 价格过期 | 不参与报价，生成风险。 |
| 单位不一致 | 尝试换算，无法换算时生成风险。 |

## 不做什么

- 不从网络自动抓价。
- 不让 AI 自动覆盖价格库。
- 不让未审核价格参与正式计算。
- 不处理人工最终改价记录。

## 验收标准

- 每个报价项可追溯价格来源。
- 价格缺失能结构化提示。
- 价格版本能固化到报价结果。
- 价格规则变更不会影响已生成历史报价。

## AI Coding 注意事项

- 不要把单价写死在报价计算代码里。
- 不要跳过审核状态。
- 不要用展示名称匹配价格。
- 不要在价格缺失时静默填 0。
