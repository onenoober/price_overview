# 零件特征融合模块

## 模块目标

将 `pdf_extract_result` 和 `step_feature_result` 融合为统一的 `part_feature`，作为后续工序识别、工程量计算和报价计算的唯一结构化输入。

## 主责

A/B 共同负责：

| 角色 | 责任 |
|---|---|
| A | 定义 `part_feature` 结构、校验、后续消费。 |
| B | 提供 PDF/STEP 解析结果并适配结构。 |

## 输入

| 输入 | 说明 |
|---|---|
| `pdf_extract_result` | PDF 字段抽取结果，可为空。 |
| `step_feature_result` | STEP 几何解析结果，可为空。 |
| 材料字典 | 用于材料标准化。 |
| 表面处理字典 | 用于表面处理标准化。 |
| 风险规则 | 用于生成结构化风险。 |

## 输出

| 输出 | 说明 |
|---|---|
| `part_feature` | 统一零件特征。 |
| `risks` | 缺文件、低置信度、未知材料、重量异常等。 |
| `evidence` | 关键字段证据。 |

## 融合优先级

| 字段 | 优先级 |
|---|---|
| 图号、名称、版本 | PDF 优先，用户手工修正最高。 |
| 材料 | PDF 原文 + 字典归一，用户手工修正最高。 |
| 包络尺寸、体积、表面积 | STEP 优先。 |
| 理论净重 | STEP + 材料密度。 |
| 图纸标注重量 | PDF 优先。 |
| 热处理、表面处理、技术要求 | PDF 优先。 |
| 孔特征、几何复杂度 | STEP 优先，PDF 高精度标注补充。 |

## 必须处理的冲突

| 冲突 | 处理 |
|---|---|
| PDF 重量和 STEP 重量偏差超过 15% | 生成 `WEIGHT_MISMATCH`，进入人工确认。 |
| PDF 材料无法归一 | 生成 `UNKNOWN_MATERIAL`。 |
| PDF 有表面处理但无法归一 | 生成 `UNKNOWN_SURFACE_TREATMENT`。 |
| PDF 和 STEP 零件类型判断冲突 | 保留候选，标记待确认。 |
| 关键字段低置信度 | 生成 `LOW_CONFIDENCE_FIELD`。 |

## `part_feature` 必须包含

| 区域 | 字段 |
|---|---|
| 基础信息 | 零件名称、图号、版本、数量。 |
| 材料 | 原文、标准编码、密度、置信度、来源。 |
| 几何 | 包络尺寸、体积、表面积、重量、零件类型。 |
| 特征 | 孔、槽、高精度、复杂度。 |
| 制造要求 | 热处理、表面处理、去毛刺、检验包装。 |
| 风险 | 结构化风险项。 |
| 证据 | 字段来源证据。 |

## 不做什么

- 不识别工序路线。
- 不计算工程量。
- 不匹配价格。
- 不生成报价。
- 不把低置信度字段当作已确认事实。

## 验收标准

- `part_feature` 通过 Schema 校验。
- 缺 PDF 或 STEP 时仍能输出结构化结果。
- 所有关键字段有来源。
- 风险项结构化。
- 后续 A 模块可直接消费，无需重新解析原始文本。

## AI Coding 注意事项

- 不要把 PDF 和 STEP 结果简单拼接成自然语言。
- 不要在融合时填入无来源的默认材料。
- 不要删除冲突字段，必须保留证据。
- 不要让后续模块直接读取 `pdf_extract_result` 替代 `part_feature`。
