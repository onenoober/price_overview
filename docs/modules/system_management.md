# 系统管理模块

## 模块目标

管理用户权限、基础字典、系统参数和操作日志，保证报价过程可控、可追溯、可维护。

## 主责

开发者 A 主责后端权限、字典、参数、日志；开发者 B 负责管理页面。

## 用户角色

| 角色 | 权限 |
|---|---|
| 报价员 | 上传文件、查看建议价、调整价格、确认报价、填写修改原因。 |
| 工艺员 | 审核工序路线、修改工序、确认工艺风险、维护工序规则建议。 |
| 价格管理员 | 导入价格档案、维护价格规则、审核价格版本。 |
| 系统管理员 | 维护用户、角色、基础字典、系统配置。 |
| 管理者 | 查看统计、偏差分析、规则命中率和价格异常。 |

## 权限规则

| 操作 | 报价员 | 工艺员 | 价格管理员 | 系统管理员 | 管理者 |
|---|---|---|---|---|---|
| 创建报价任务 | 是 | 是 | 否 | 是 | 否 |
| 上传文件 | 是 | 是 | 否 | 是 | 否 |
| 修改工序 | 是 | 是 | 否 | 是 | 否 |
| 修改价格 | 是 | 否 | 是 | 是 | 否 |
| 确认报价 | 是 | 否 | 否 | 是 | 否 |
| 维护价格规则 | 否 | 否 | 是 | 是 | 否 |
| 维护字典 | 否 | 否 | 部分 | 是 | 否 |
| 查看统计 | 否 | 否 | 是 | 是 | 是 |

## 基础字典

必须支持：

| 字典 | 说明 |
|---|---|
| 材料字典 | 材料编码、名称、别名、密度、类别。 |
| 工序字典 | 工序编码、名称、排序、自动报价标记。 |
| 表面处理字典 | 编码、名称、别名、计价单位。 |
| 风险标签字典 | 编码、等级、是否必确认、默认说明。 |
| 单位字典 | 单位类型、换算规则。 |

## 系统参数

| 参数 | 说明 |
|---|---|
| `tax_rate` | 税率。 |
| `management_fee_rule` | 固定规则：管理费 = 材料费 × 5%，不做参数化调整。 |
| `process_price_standard` | 当前加工费标准：华南工序计价标准表，按工序单价和起步价计算。 |
| `surface_treatment_price_provider` | 表面处理价格来源：价格库优先；缺失时可用 Tavily + GPT 搜索候选价。 |
| `surface_treatment_gpt_estimate_enabled` | 表面处理市场价缺失时是否启用 GPT-only 估算价；估算价必须进入复核。 |
| `weight_mismatch_threshold` | 重量偏差阈值，第一版默认 15%。 |
| `low_confidence_threshold` | 低置信度阈值。 |
| `rounding_rule` | 报价取整规则。 |
| `max_upload_size` | 上传文件大小限制。 |

## 日志审计

必须记录：

| 操作 | 日志内容 |
|---|---|
| 登录 | 用户、时间、结果。 |
| 上传 | 文件、任务、用户、时间。 |
| 解析 | 任务、文件、状态、错误。 |
| 核价 | 任务、价格版本、用户、时间。 |
| 修改 | 目标、旧值、新值、原因。 |
| 确认 | 报价 ID、确认人、确认时间。 |
| 导出 | 报价 ID、格式、导出人、时间。 |
| 价格维护 | 规则 ID、变更内容、审核状态。 |

## 不做什么

- 不在第一版做复杂组织架构审批流。
- 不自动授权越权操作。
- 不允许未审核价格生效。
- 不允许删除关键审计日志。

## 验收标准

- 不同角色权限可区分。
- 关键字典可维护。
- 系统参数可配置。
- 关键操作有审计日志。
- 价格规则审核状态可控。

## AI Coding 注意事项

- 不要把权限只放在前端控制。
- 不要把系统参数写死在业务代码中。
- 不要允许物理删除审计日志。
- 不要让价格维护绕过审核状态。
