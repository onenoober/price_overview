# 最终核对与报价输出模块

## 模块目标

在统一页面展示零件特征、工序、工程量、报价明细、风险和人工修改入口，并支持最终确认和导出报价明细。

## 主责

开发者 B 主责页面和导出，开发者 A 主责保存、校验和状态流转。

## 输入

| 输入 | 说明 |
|---|---|
| `part_feature` | 零件特征。 |
| `process_route` | 工序路线。 |
| `quantity_result` | 工程量。 |
| `quote_result` | 报价结果。 |
| `human_override` | 人工修改记录。 |

## 输出

| 输出 | 说明 |
|---|---|
| 人工修改记录 | `human_override`。 |
| 最终确认报价 | 确认后的 `quote_result`。 |
| 导出文件 | 报价明细和确认结果。 |
| 操作日志 | 修改、确认、导出记录。 |

## 页面区域

| 区域 | 展示内容 |
|---|---|
| 任务信息 | 客户、零件、图号、数量、状态。 |
| 文件信息 | PDF、STEP、附件、版本、解析状态。 |
| 零件特征 | 材料、尺寸、重量、类型、制造要求。 |
| 工序路线 | 工序、排序、触发原因、置信度。 |
| 工程量 | 数值、单位、公式、依据。 |
| 报价明细 | 单价、金额、来源、公式。 |
| 风险提示 | 风险等级、说明、是否必确认。 |
| 修改记录 | 字段、旧值、新值、原因、操作人。 |
| 汇总确认 | 初始报价、调整金额、最终确认价。 |

## 可编辑项

| 项 | 要求 |
|---|---|
| 工序 | 可新增、删除、调整顺序。 |
| 工程量 | 可人工修正，必须填原因。 |
| 单价 | 可人工修正，必须填原因。 |
| 金额 | 可人工修正，必须填原因。 |
| 风险 | 可确认或补充说明。 |
| 最终确认价 | 可调整，必须填确认说明。 |

## 页面状态

| 状态 | 要求 |
|---|---|
| `loading` | 显示解析或计算中。 |
| `success` | 展示完整结果。 |
| `warning` | 展示待确认风险。 |
| `error` | 展示错误和重试入口。 |
| `readonly` | 已确认或作废后只读。 |

## 确认规则

| 条件 | 是否可确认 |
|---|---|
| 无 blocking 风险 | 可确认。 |
| 有 blocking 风险且未确认 | 不可确认。 |
| 有价格缺失且未补录 | 不可确认。 |
| 修改原因缺失 | 不可确认。 |
| 报价已作废 | 不可确认。 |

## 导出内容

导出必须包含：

| 内容 | 要求 |
|---|---|
| 任务信息 | 客户、零件、图号、数量。 |
| 文件信息 | 文件名、版本。 |
| 工艺路线 | 工序、原因、置信度。 |
| 工程量 | 数值、单位、公式。 |
| 报价明细 | 单价、金额、来源。 |
| 风险提示 | 编码、等级、说明、确认状态。 |
| 修改记录 | 旧值、新值、原因。 |
| 汇总 | 系统初始报价、最终确认价。 |

## 不做什么

- 不在前端重新计算核心报价。
- 不在页面中直接修改价格规则。
- 不隐藏必确认风险。
- 不允许无原因修改。
- 不导出无追溯信息的报价。

## 验收标准

- 页面展示字段与接口返回一致。
- 人工修改记录完整。
- 有 blocking 风险时确认按钮不可用或确认失败。
- 导出内容包含初始报价和最终确认价。
- 已确认报价只读。

## AI Coding 注意事项

- 不要在页面组件里复制报价公式。
- 不要只在前端校验修改原因，后端也必须校验。
- 不要依赖未写入 API 文档的字段。
- 不要把风险提示作为纯文本丢失结构。
