# 测试与验收

## 测试目标

测试必须验证系统是否能稳定完成：

```text
文件输入
-> 结构化特征
-> 工序路线
-> 工程量
-> 价格明细
-> 初始报价
-> 人工核对
-> 最终确认
-> 历史留痕
```

## 测试分类

| 类型 | 目标 | 主责 |
|---|---|---|
| 单元测试 | 验证规则、计算、状态流转。 | A/B |
| 契约测试 | 验证输出符合 JSON Schema。 | A/B |
| 集成测试 | 验证跨模块链路。 | A/B |
| 页面测试 | 验证核对页、上传页、导出页交互。 | B |
| 样本回归 | 验证黄金样本和边界样本。 | A/B |
| 验收统计 | 输出准确率、召回率、误判率、偏差。 | A/B |

## 黄金样本

黄金样本用于验证常规场景。

要求：

| 要求 | 标准 |
|---|---|
| 数量 | 30-50 个。 |
| 文件 | 尽量包含 PDF + STEP。 |
| 零件类型 | 精密小件、薄片件、板件、简单块件、异形小件。 |
| 材料 | 覆盖 SKD11、S45C、SUS304、AL6061、常见模具钢。 |
| 预期结果 | 必须有人工确认的标准工序和参考报价。 |

每个黄金样本必须记录：

```text
sample_id
part_name
material
pdf_file
step_file
expected_required_operations
expected_risk_codes
reference_quote_amount
manual_notes
```

## 边界样本

边界样本用于验证异常和待确认规则。

要求：

| 场景 | 必须覆盖 |
|---|---|
| 缺 PDF | 有 STEP，无 PDF。 |
| 缺 STEP | 有 PDF，无 STEP。 |
| 重量异常 | PDF 重量与 STEP 重量偏差超过 15%。 |
| 未知材料 | 材料不在字典。 |
| 未知表面处理 | 表面处理无法归一。 |
| 高精度 | H7、E8、G6、±0.01、Ra0.8。 |
| 高风险几何 | 小 R、窄槽、深孔、薄壁、长悬臂。 |
| 价格缺失 | 材料价或工序价缺失。 |
| 低置信度 | 关键字段置信度低于阈值。 |

## 验收指标

| 指标 | 第一版标准 | 计算口径 |
|---|---:|---|
| PDF 关键字段抽取准确率 | >= 90% | 正确字段数 / 应抽字段数。 |
| STEP 基础几何解析成功率 | >= 95% | 解析成功样本数 / 有 STEP 样本数。 |
| 必选工序召回率 | >= 90% | 命中必选工序数 / 应有必选工序数。 |
| 工序误判率 | <= 15% | 错误新增工序数 / 系统输出工序数。 |
| 必锁场景命中率 | 100% | 命中必确认风险数 / 应命中风险数。 |
| 报价明细可解释率 | 100% | 有公式和依据的报价项 / 全部报价项。 |
| 人工修改记录完整率 | 100% | 有原因的修改记录 / 全部修改记录。 |
| 黄金样本回归通过率 | 100% | 通过黄金样本数 / 黄金样本总数。 |

## 必须通过的链路测试

### 正常链路

输入：PDF + STEP + 已知材料 + 完整价格。

期望：

- 生成 `part_feature`。
- 生成 `process_route`。
- 生成 `quantity_result`。
- 生成 `quote_result`。
- 状态为 `priced` 或 `pending_review`。
- 页面可展示报价。
- 可人工确认。
- 可导出。

### 缺文件链路

输入：只上传 PDF 或只上传 STEP。

期望：

- 仍可生成带风险的初始报价。
- 风险包含 `MISSING_PDF` 或 `MISSING_STEP`。
- 状态进入 `pending_review`。
- 未确认前不得进入 `confirmed`。

### 价格缺失链路

输入：已知零件特征，但材料或工序无价格。

期望：

- 生成 `MISSING_PRICE` 风险。
- 缺失报价项不得静默为 0。
- 页面提示人工补录或修改。

### 人工修改链路

输入：报价员修改工序、单价、金额或最终价。

期望：

- 修改原因必填。
- 系统初始值保留。
- `human_override` 记录完整。
- 最终确认价与初始报价可对比。

## 回归报告格式

每次正式联调后必须输出：

| 字段 | 内容 |
|---|---|
| 测试时间 | 执行时间。 |
| 代码版本 | commit SHA。 |
| 样本数量 | 黄金样本、边界样本数量。 |
| 通过数量 | 通过样本数量。 |
| 阻塞问题 | 阻塞上线的问题。 |
| 非阻塞问题 | 可后续优化的问题。 |
| 指标统计 | PDF、STEP、工序、风险、报价。 |
| 结论 | 是否可进入下一阶段。 |

## 不通过条件

出现以下任一情况，不得验收通过：

| 条件 | 说明 |
|---|---|
| 必锁风险漏报 | 必须人工确认的风险未提示。 |
| 报价项无解释 | 报价明细缺公式、来源或依据。 |
| 人工修改无记录 | 修改没有原因或没有留痕。 |
| AI 直接给最终价 | 违反业务约束。 |
| 初始报价被覆盖 | 无法追溯系统原始报价。 |
| 黄金样本回归失败 | 常规链路不可稳定复现。 |
